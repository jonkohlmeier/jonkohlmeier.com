# Puffs of Smoke

Jon Kohlmeier’s personal publication. Built with Astro, Markdown content collections, and a small Tailwind/CSS design system.

## Local development

Requires Node.js 22.23.4 or newer and npm 10.9.4 for lockfile changes.

```bash
npm install
npm run dev
```

The development server runs at <http://localhost:4321>.

| Command | Description |
| --- | --- |
| `npm run dev` | Start the local development server |
| `npm run build` | Build the static site in `dist/` |
| `npm run preview` | Preview the production build |
| `npm test` | Build and run the Playwright checks |

## Publishing writing

Writing lives in `src/content/blog/`. Create one Markdown or MDX file per piece; the filename becomes the public slug. Existing articles use `/blog/<slug>/`, and those URLs should not change.

```yaml
---
title: "A clear, specific title"
description: "One sentence used in article lists, RSS, and search metadata."
pubDate: 2026-11-16
category: work-and-ideas
format: essay
tags:
  - leadership
  - systems
draft: false
---
```

### Categories

- `work-and-ideas` — leadership, technology, AI, Revenue Operations, systems, and organizations
- `life-and-reflection` — faith, family, values, personal growth, and everyday life
- `the-finer-things` — books, cocktails, coffee, wine, movies, travel, and hobbies

### Formats

- `essay` — long-form writing; this is the default when `format` is omitted
- `note` — short observations and reflections
- `roundup` — collections, recommendations, and discoveries

Optional fields include `updatedDate`, `heroImage`, `heroAlt`, `canonical`, and `featured`. Set `featured: true` on the piece that should lead the homepage; if none is marked, the newest published piece is used. Set `draft: true` to keep a piece out of generated pages and RSS.

## Site structure

- `src/content.config.ts` — typed article metadata
- `src/data/editorial.ts` — category labels, format labels, sorting, and article paths
- `src/layouts/` — shared site and article layouts
- `src/pages/` — Astro routes, including legacy `/blog/` and category paths
- `src/styles/global.css` — editorial design tokens and responsive styles

RSS is generated at `/rss.xml`; the sitemap is generated by Astro. Theme preference is stored locally in the browser. The static site deploys to GitHub Pages through `.github/workflows/deploy.yml` when changes reach `master`.
